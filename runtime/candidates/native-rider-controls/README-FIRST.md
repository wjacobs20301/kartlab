# Native Kart Lab for TOTK 1.1.0

This development build targets TOTK **1.1.0** (build D5AD6AC71EF53E3E52417C1B81DBC9B4142AA3B3). It uses the locally extracted Mario standard kart and native TOTK riding. Tested in Ryujinx 1.3.3; modded Switch execution still needs hardware validation.

Load a mainland save, stand on open ground and briefly press **ZL + ZR + D-pad Up**, then release all three. If the native material menu appears briefly, the spawn request waits until it closes. On the PS4 mapping this is **L2 + R2 + Up**. The shortcut spawns a kart, or recalls your existing unoccupied kart. Approach the kart's rear until **A: Control** appears; press A (PS4 Circle). The left stick accelerates, reverses and steers. Release it to brake. Press **B** (PS4 Cross) to dismount. The native camera follows Link. There is no remote-drive Right shortcut in this build.

The normal startup controller waits for your input. It does not load a save, automatically spawn a kart, move Link into position, or run a timed test. It compiles once at startup and keeps one yielding module alive. No network listener starts. A tracked kart remains available after dismounting. The same shortcut recalls it without creating a duplicate; dismount before recalling. A world load clears the temporary reference. Actor lifetime tracking still uses guarded temporary references and needs broader stress testing.

The current handling uses a gentle 2.5-unit forward speed cap, a 1-unit reverse cap, gradual acceleration and native linear/angular velocity requests. An automatic parking brake uses gentle physics feedback after dismounting; mounting releases it. Broader terrain and moving-platform interaction still need testing. This is an original prototype controller, not the complete Mario Kart physics engine. Native gravity and collision remain active.

This experimental asset arrangement changes Control Stick actors to use the kart submodel and Cart contact hulls. It also replaces the native Cart visual, shared textures and vehicle idle animations. Other uses of these actors/resources are affected. Use the isolated development mod; a separate custom actor remains future work. A native TOTK seated lower-body pose is combined with the vehicle upper-body animation. Seat and hand fit are still being refined, and the entry/exit transitions use native TOTK actions. Dynamic tire spin, independent suspension, drift, boost and Mario characters are not implemented yet.

The runtime includes fixes for uninitialized spawn flags and an incorrect upstream TOTK1.1.0 linear-velocity address, plus an additive angular-velocity binding. Exact pinned source, GPL license, source patches and byte-identical reproduction tools are included in the package. The original games and extracted inputs remain untouched.

For Ryujinx, install the package's `mod/exefs` and `mod/romfs` together under a single TOTK mod directory and copy `switch-sdcard` contents into its SD-card directory. Restart the game after changing executable/assets. For Atmosphere, the intended layout is `atmosphere/contents/0100F2C0115B6000/{exefs,romfs}` plus `totk_lotuskit` at the SD root; hardware compatibility is unverified. Disable this isolated mod and remove its startup script to restore ordinary actors and controls. Keep the provided backups of any preceding mod and save.
