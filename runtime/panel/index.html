Kart movement lab

TOTK 1.1.0 · lotuskit 59dcfcc · experimental integration prototype

Spawns TOTK’s native wheeled cart. This tests actor creation, collision and rigid-body movement. Link stays separate. Mario Kart models and handling are still being integrated.

In game, press L R ZL ZR + − together to start lotuskit’s server. Use the Switch’s local IPv4 address when testing hardware.

Once the in-game message says “cart ready,” hold a direction below or use W/A/S/D while this page has focus. Space brakes. Reverse is S. Each continuous test is limited to 30 seconds. Controls do not attach Link or the camera.

Clear the watcher before fast travel, shrine entry or loading a save. The upstream watcher can retain dead actors. Use a test save. Releasing controls or leaving this page stops horizontal drive; a lost connection can leave the physical cart coasting.
